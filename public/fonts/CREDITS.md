# Gallery typography

Glametrix, Onest and IBM Plex Mono are the current Night Gallery type system. Glametrix Light, Regular and Bold carry the hero and section titles with clean geometric proportions. The family was downloaded from FontSpace, where designer gluk publishes it under the SIL Open Font License; the downloaded license is included as `glametrix-OFL.txt`. Onest carries reading text and interface copy, and IBM Plex Mono is limited to technical labels and metrics.

- https://www.fontspace.com/glametrix-font-f16913
- https://github.com/google/fonts/tree/main/ofl/onest
- https://github.com/google/fonts/tree/main/ofl/ibmplexmono
- The Google Fonts license texts are included as `onest-OFL.txt` and `ibm-plex-mono-OFL.txt`.

Migha, Syncopate, Marcellus, Syne and Bricolage Grotesque were used in earlier gallery versions.

Cabinet Grotesk and Satoshi by Indian Type Foundry, obtained from the official Fontshare API and self-hosted as WOFF2 variable fonts with `next/font/local`.

- https://www.fontshare.com/fonts/cabinet-grotesk
- https://www.fontshare.com/fonts/satoshi
- https://www.fontshare.com/licenses

Cabinet Grotesk and Satoshi were used in an earlier gallery version.

An earlier Night Gallery version used Manrope (Mikhail Sharanda / Manrope Project Authors) for headings and Source Sans 3 (Paul D. Hunt / Adobe) for body text.

- https://github.com/google/fonts/tree/main/ofl/manrope
- https://github.com/google/fonts/tree/main/ofl/sourcesans3
- Their SIL Open Font License texts are included as `manrope-OFL.txt` and `source-sans-3-OFL.txt`.

The original portfolio font stack is preserved.

Clash Display and General Sans by Indian Type Foundry were obtained from the official Fontshare API and self-hosted as variable WOFF2 files with `next/font/local`. Both are retained from earlier versions.
